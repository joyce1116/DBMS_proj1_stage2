## 目录用途

```text
app/
  main.py     应用入口
  auth/       注册、登录、会话和密码处理
  surveys/    问卷、题目、发布和分享
  database/   MongoDB连接、初始化和显式迁移
  core/       公共配置、UTC时间
tests/        自动化用例，包含真实 MongoDB 测试
scripts/      启动数据库、初始化、迁移和演示
docs/         上面列出的六份文档
backups/      旧文档、旧工具、数据库备份，仅本地保留
.runtime/     MongoDB 数据和运行日志，仅本地保留
.venv/        Python 环境，仅本地保留
```

直接在当前目录开发，不另建提交副本。上传内容为 `app/`、`scripts/`、`tests/`、`docs/`、`requirements.txt`、`pytest.ini`、`.env.example`；排除 `.git/`、`.venv/`、`.runtime/`、`backups/`、`__pycache__/` 和实际 `.env`。当前功能尚未齐全，尚不是完整第一阶段交付。
