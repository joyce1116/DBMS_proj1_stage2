# 运行与复现

在项目根目录执行。实测环境：Windows PowerShell、Python 3.13.9、MongoDB 6.0.29、FastAPI 0.143.1、PyMongo 4.19.0；依赖版本固定于 `requirements.txt`。命令使用 `-B` 避免产生源码缓存。

## 1. 准备Python（已有.venv可跳过）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

无需激活环境。可选复制 `.env.example` 为 `.env`。默认 `MONGO_URI=mongodb://127.0.0.1:27018`、`MONGO_DB=survey_phase1`、`MONGO_TIMEOUT_MS=3000`、`SESSION_TTL_SECONDS=86400`；环境变量优先。

## 2. 终端A：启动MongoDB

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_mongo.ps1
```

需安装MongoDB且PATH可找到 `mongod`。仅监听本机27018，数据在 `.runtime/mongo-data`；Ctrl+C停止并保留数据。端口占用时先确认现有实例，不随意终止进程。

## 3. 终端B：初始化并启动API

```powershell
.\.venv\Scripts\python.exe -B -m scripts.init_db
.\.venv\Scripts\python.exe -B -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

当前开发库已为schema v3；新库直接初始化。**只有旧库需要迁移**，必须停止API、保持MongoDB运行。旧v1先执行：

```powershell
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v2 --dry-run
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v2
```

随后执行v2→v3；接续旧v2库则只执行以下两行：

```powershell
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v3 --dry-run
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v3
```

迁移自动建立原文备份和审计，可续跑；未知结构拒绝，不能清库解决。不要对v3再执行旧v2迁移。设计见文档02。

## 4. 终端C：演示与测试

```powershell
# 真实HTTP演示，需要A、B；不打印密码和token。
.\.venv\Scripts\python.exe -B -X utf8 -m scripts.demo

# 全量测试仅需A；测试自行建立API和随机隔离数据库。
.\.venv\Scripts\python.exe -B -m pytest -q

# 无需数据库的离线测试。
.\.venv\Scripts\python.exe -B -m pytest -m 'not integration' -q

# 只复现本轮跳转、提交、统计和迁移。
.\.venv\Scripts\python.exe -B -m pytest tests/test_navigation.py tests/test_responses_integration.py tests/test_responses_migration.py -q
```

演示注册3个临时命名账号，创建4题和3类跳转规则，发布后保存3份答卷（其中同一账号填2次、1份匿名），检查重试/权限/统计，关闭并退出。预期平均年龄18、文本2条。**演示会在开发库保留这些账号、问卷和答卷**，每次运行都新增一组。

交互API文档：`http://127.0.0.1:8000/docs`。先注册/登录，用返回的token点击Authorize；准确请求/响应契约见 `/openapi.json`。`/docs` UI依赖外部CDN，Python演示不依赖它。后续前端可用navigate接口逐题填写，再用responses接口提交。

## 5. 结束与上传

先在终端B按Ctrl+C，再在A按Ctrl+C。不移动或清空数据库目录。

上传当前 `app/`、`scripts/`、`tests/`、`docs/`、`requirements.txt`、`pytest.ini`、`.env.example`。排除 `.git/`、`.venv/`、`.runtime/`、`backups/`、`__pycache__/` 和实际 `.env`；不创建另一套提交目录。
