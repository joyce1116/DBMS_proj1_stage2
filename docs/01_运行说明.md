# 运行与复现

在项目根目录执行。实测环境：Windows PowerShell、Python 3.13.9、MongoDB 6.0.29、FastAPI 0.143.1、PyMongo 4.19.0；依赖版本固定于 `requirements.txt`。前端无需Node.js、构建命令或外部CDN。命令使用 `-B` 避免产生源码缓存。

## 1. 准备Python（已有.venv可跳过）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

无需激活环境。可选复制 `.env.example` 为 `.env`。默认 `MONGO_URI=mongodb://127.0.0.1:27018`、`MONGO_DB=survey_phase1`、`MONGO_TIMEOUT_MS=3000`、`SESSION_TTL_SECONDS=86400`；环境变量优先。

## 2. 终端A：启动MongoDB

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_mongo.ps1
```

需安装MongoDB且PATH可找到 `mongod`。仅监听本机27018，数据在 `.runtime/mongo-data`；Ctrl+C停止并保留数据。端口占用时先确认现有实例，不随意终止进程。

## 3. 终端B：初始化并启动API

```powershell
.\.venv\Scripts\python.exe -B -m scripts.init_db
.\.venv\Scripts\python.exe -B -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 **http://127.0.0.1:8000/** 使用网页，不要直接双击HTML文件。当前开发库已为schema v3；新库直接初始化，本轮前端不需要额外迁移。**只有旧库需要迁移**，必须停止API、保持MongoDB运行。旧v1先执行：

```powershell
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v2 --dry-run
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v2
```

随后执行v2→v3；接续旧v2库则只执行以下两行：

```powershell
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v3 --dry-run
.\.venv\Scripts\python.exe -B -m scripts.migrate_surveys_v3
```

迁移自动建立原文备份和审计，可续跑；未知结构拒绝，不能清库解决。不要对v3再执行旧v2迁移。设计见文档02。

## 4. 终端C：演示与测试

```powershell
# 真实HTTP演示，需要A、B；不打印密码和token。
.\.venv\Scripts\python.exe -B -X utf8 -m scripts.demo

# 常规测试仅需A；默认不启动浏览器，自行建立API和随机隔离数据库。
.\.venv\Scripts\python.exe -B -m pytest -q

# 无需数据库的离线测试。
.\.venv\Scripts\python.exe -B -m pytest -m 'not integration' -q

# 真实Edge浏览器测试，仅需A；自动启动独立HTTP服务和隔离数据库。
.\.venv\Scripts\python.exe -B -X utf8 -m pytest tests/browser -m browser -q
```

演示注册3个临时命名账号，创建4题和3类跳转规则，发布后保存3份答卷（其中同一账号填2次、1份匿名），检查重试/权限/统计，关闭并退出。预期平均年龄18、文本2条。**演示会在开发库保留这些账号、问卷和答卷**，每次运行都新增一组。

交互API文档：`http://127.0.0.1:8000/docs`。先注册/登录，用返回的token点击Authorize；准确请求/响应契约见 `/openapi.json`。`/docs` UI依赖外部CDN，Python演示不依赖它。用户网页不依赖此API文档页面。

浏览器测试使用Playwright 1.64.0和本机Edge，本机实测Edge 155.0.4283.45，无需下载浏览器。若其他机器没有Edge，可安装Chromium后切换：

```powershell
.\.venv\Scripts\python.exe -m playwright install chromium
$env:PLAYWRIGHT_CHANNEL = 'chromium'
.\.venv\Scripts\python.exe -B -X utf8 -m pytest tests/browser -m browser -q
```

截图保存在 `.runtime/browser/`，不随代码上传。普通运行和常规测试均不要求启动浏览器。Edge通道用法参考[Playwright官方说明](https://playwright.dev/python/docs/browsers)。

## 5. 网页操作复现

1. 打开首页，选择“注册账号”，注册后进入“我的问卷”。已有账号直接登录。
2. 点击“创建问卷”，填写标题/说明及匿名、重复选项；添加单选、多选、文本、数字题，弹窗内分别保存。
3. 在“跳转规则”选来源题、条件、匹配选项或数字、后方目标题/结束，逐条保存；列表顺序代表判断优先级。
4. 在“问卷设置”设置截止等信息并保存，再发布；发布后内容固定，页面会出现分享链接。
5. 复制链接到另一个浏览器的无痕窗口，用另一账号注册/登录，逐题填写，核对后可选择匿名并提交；用“修改”可回退，后续题目重新判断。
6. 回创建者窗口点击“查看统计”，可选单题查看填空内容或切换“答卷明细”，内容超20条可翻页；新答卷可点“刷新数据”。问卷页可关闭收集。

会话保留在当前页签，刷新无需重新登录。提交结果未确认时使用“重试确认提交”；刷新后也会恢复同一请求确认，避免重复保存。填写中的未提交答案不会自动保存。

## 6. 结束与上传

先在终端B按Ctrl+C，再在A按Ctrl+C。不移动或清空数据库目录。

上传当前 `app/`、`scripts/`、`tests/`、`docs/`、`requirements.txt`、`pytest.ini`、`.env.example`。排除 `.git/`、`.venv/`、`.runtime/`、`backups/`、`__pycache__/` 和实际 `.env`；不创建另一套提交目录。
